# Loops in C++ — Detailed Notes

## 1. What is a Loop?

A **loop** is a programming construct that repeatedly executes a block of code while a specified condition is satisfied.

### Why do we need loops?

Without loops, repetitive work would require writing the same code many times.

For example, suppose we want to print numbers from 1 to 5.

Without a loop:

```cpp
std::cout << 1 << '\n';
std::cout << 2 << '\n';
std::cout << 3 << '\n';
std::cout << 4 << '\n';
std::cout << 5 << '\n';
```

With a loop:

```cpp
for (int i = 1; i <= 5; i++)
{
    std::cout << i << '\n';
}
```

The loop makes the code:

* **Shorter**
* **More reusable**
* **Easier to modify**
* **Less repetitive**
* **Less prone to copy-paste errors**

### General idea

A loop generally follows this pattern:

```text
Start
  ↓
Check condition
  ↓
Is condition true?
  ├── No → Exit loop
  └── Yes
       ↓
   Execute body
       ↓
   Update state
       ↓
   Check condition again
```

---

# 2. Loops in Real Programs

Loops aren't just useful for simple counting.

Interactive programs such as games, graphical applications, and simulations often need to keep running until the user quits.

For example:

```cpp
bool running = true;

while (running)
{
    // Process input
    // Update game state
    // Render frame
}
```

Conceptually, a game loop repeatedly performs tasks such as:

```text
while (game is running)
{
    receive user input
    update game state
    render the next frame
}
```

This allows the program to continuously respond to the user rather than executing once and terminating.

# 3. The `for` Loop

The `for` loop is one of the most commonly used loops in C++.

### Basic syntax

```cpp
for (initialization; condition; update)
{
    // loop body
}
```

Example:

```cpp
for (int i = 0; i < 5; i++)
{
    std::cout << i << '\n';
}
```

Output:

```text
0
1
2
3
4
```

---

## 4. The Three Parts of a `for` Loop

A `for` loop has three expressions:

```cpp
for (initialization; condition; update)
```

### 4.1 Initialization

```cpp
int i = 0
```

The initialization runs **once**, before the first condition check.

Example:

```cpp
for (int i = 0; i < 5; i++)
```

Here:

```cpp
int i = 0;
```

creates the variable `i` and gives it an initial value of `0`.

The variable `i` is commonly used as an **index** or **iterator**.

---

### 4.2 Condition

```cpp
i < 5
```

The condition determines whether another iteration should occur.

If the condition is:

```cpp
true
```

the loop body executes.

If it is:

```cpp
false
```

the loop terminates.

Importantly, the condition is checked **before every iteration**.

---

### 4.3 Body

The body contains the code that should be repeatedly executed.

```cpp
{
    std::cout << i << '\n';
}
```

Every time the condition evaluates to `true`, this block executes.

---

### 4.4 Update

```cpp
i++
```

The update expression executes after the body.

`i++` means:

```cpp
i = i + 1;
```

The update happens before the next condition check.

---

# 5. Complete Execution of a `for` Loop

Consider:

```cpp
for (int i = 0; i < 3; i++)
{
    std::cout << i << '\n';
}
```

The execution proceeds like this:

### Step 1 — Initialization

```cpp
int i = 0;
```

### Step 2 — Check condition

```cpp
i < 3
```

`0 < 3` → `true`

### Step 3 — Execute body

```cpp
std::cout << i << '\n';
```

Prints:

```text
0
```

### Step 4 — Update

```cpp
i++;
```

Now:

```text
i = 1
```

### Step 5 — Check condition again

```text
1 < 3 → true
```

Prints `1`.

### Step 6 — Update

```text
i = 2
```

### Step 7 — Check again

```text
2 < 3 → true
```

Prints `2`.

### Step 8 — Update

```text
i = 3
```

### Step 9 — Check again

```text
3 < 3 → false
```

The loop terminates.

### Overall flow

```text
initialization
      ↓
condition ──false──→ exit
   │
 true
   ↓
 body
   ↓
 update
   │
   └────────→ condition
```

---

# 6. `i++`, `i--`, and Other Updates

The update doesn't have to be `i++`.

### Increment by 1

```cpp
i++;
```

### Decrement by 1

```cpp
i--;
```

### Increment by 2

```cpp
i += 2;
```

Example:

```cpp
for (int i = 0; i < 10; i += 2)
{
    std::cout << i << '\n';
}
```

Output:

```text
0
2
4
6
8
```

### Decrement

```cpp
for (int i = 5; i > 0; i--)
{
    std::cout << i << '\n';
}
```

Output:

```text
5
4
3
2
1
```

---

# 7. All Three Parts of `for` Are Optional

A `for` loop doesn't necessarily need all three expressions.

For example:

```cpp
int i = 0;

for (; i < 5; )
{
    std::cout << i << '\n';
    i++;
}
```

This is valid C++.

The initialization and update were moved outside the `for` declaration.

---

## 8. Infinite `for` Loops

You can omit the condition completely:

```cpp
for (;;)
{
    // code
}
```

An empty condition is treated as always true, so this creates an **infinite loop**.

It can be terminated using `break`:

```cpp
for (;;)
{
    // do something

    if (someCondition)
        break;
}
```

Infinite loops aren't automatically bad. They can be useful for programs that are deliberately designed to run continuously, provided there is an appropriate way to terminate or control them.

---

# 9. The `while` Loop

The `while` loop repeatedly executes its body while a condition is `true`.

### Syntax

```cpp
while (condition)
{
    // loop body
}
```

Example:

```cpp
int i = 0;

while (i < 5)
{
    std::cout << i << '\n';
    i++;
}
```

Output:

```text
0
1
2
3
4
```

---

# 10. How a `while` Loop Works

Consider:

```cpp
int i = 0;

while (i < 3)
{
    std::cout << i << '\n';
    i++;
}
```

Execution:

```text
i = 0
  ↓
i < 3 ?
  ↓
true
  ↓
print i
  ↓
i++
  ↓
check condition again
```

Eventually:

```text
i = 3
```

Then:

```cpp
3 < 3
```

is false, so the loop terminates.

---

# 11. Important Property of `while`

A `while` loop checks its condition **before** executing its body.

Therefore, it is possible for the body to execute **zero times**.

Example:

```cpp
int i = 10;

while (i < 5)
{
    std::cout << i << '\n';
}
```

The condition:

```cpp
10 < 5
```

is immediately false.

Therefore, nothing inside the body executes.

This makes `while` a **pre-test loop**.

---

# 12. `for` vs `while`

At the machine/compiler level, a simple `for` loop and an equivalent `while` loop can represent essentially the same control flow.

For example:

```cpp
for (int i = 0; i < 5; i++)
{
    std::cout << i << '\n';
}
```

can conceptually be written as:

```cpp
int i = 0;

while (i < 5)
{
    std::cout << i << '\n';
    i++;
}
```

The major difference is generally **how the programmer expresses their intent**, rather than some fundamental performance difference.

---

## When should you use each?

### Use `for` when:

* You have a counter/index.
* You know or can clearly express the iteration pattern.
* You are iterating a particular number of times.
* You are traversing an array or similar sequence.

Example:

```cpp
for (int i = 0; i < size; i++)
{
    std::cout << array[i] << '\n';
}
```

The initialization, condition, and update are all visible together.

---

### Use `while` when:

* The loop is primarily controlled by a condition/state.
* The number of iterations isn't naturally expressed as a counter.
* You are waiting for something to happen.
* You have an existing Boolean condition.

Example:

```cpp
while (isGameRunning)
{
    // process game
}
```

The intention is very clear:

> Keep running while the game is running.

---

# 13. The `do-while` Loop

C++ also provides a third traditional loop:

```cpp
do
{
    // loop body
}
while (condition);
```

Notice the **semicolon** after the condition:

```cpp
while (condition);
```

---

## Key difference

A `while` loop checks the condition **before** the body:

```text
condition
   ↓
 body
```

A `do-while` loop checks the condition **after** the body:

```text
body
 ↓
condition
 ↓
repeat?
```

Therefore, a `do-while` loop executes its body **at least once**.

---

# 14. Example: `while` vs `do-while`

### `while`

```cpp
int i = 10;

while (i < 5)
{
    std::cout << "Hello\n";
}
```

Output:

```text
nothing
```

The condition is false from the beginning.

---

### `do-while`

```cpp
int i = 10;

do
{
    std::cout << "Hello\n";
}
while (i < 5);
```

Output:

```text
Hello
```

Even though:

```cpp
i < 5
```

is false, the body has already executed once.

---

# 15. Useful Example of `do-while`

A menu is a common conceptual use:

```cpp
int choice;

do
{
    std::cout << "1. Play\n";
    std::cout << "2. Settings\n";
    std::cout << "3. Quit\n";

    std::cin >> choice;

} while (choice != 3);
```

The menu needs to be displayed **at least once**, so `do-while` naturally expresses this behavior.

---

# 16. Comparison Table

| Feature                          | `for`       | `while`     | `do-while` |
| -------------------------------- | ----------- | ----------- | ---------- |
| Condition checked                | Before body | Before body | After body |
| Minimum executions               | 0           | 0           | **1**      |
| Initialization built into syntax | Yes         | No          | No         |
| Update built into syntax         | Yes         | No          | No         |
| Good for counters                | **Yes**     | Yes         | Sometimes  |
| Good for condition/state loops   | Yes         | **Yes**     | Yes        |
| Can be infinite                  | Yes         | Yes         | Yes        |

# 17. Common Mistakes

## Forgetting to update the loop variable

```cpp
int i = 0;

while (i < 5)
{
    std::cout << i << '\n';
}
```

`i` never changes.

Therefore:

```cpp
i < 5
```

remains true forever.

This creates an **infinite loop**.

Correct:

```cpp
while (i < 5)
{
    std::cout << i << '\n';
    i++;
}
```

---

## Off-by-one errors

Compare:

```cpp
for (int i = 0; i < 5; i++)
```

with:

```cpp
for (int i = 0; i <= 5; i++)
```

The first executes for:

```text
0 1 2 3 4
```

The second executes for:

```text
0 1 2 3 4 5
```

When working with an array of size 5, the valid indices are normally:

```text
0 1 2 3 4
```

so:

```cpp
i < 5
```

is usually appropriate.

# 18. Key Concepts to Remember

### `for`

```cpp
for (initialization; condition; update)
{
    body;
}
```

Think:

> **Start → Check → Execute → Update → Repeat**

---

### `while`

```cpp
while (condition)
{
    body;
}
```

Think:

> **While this condition is true, keep doing this.**

---

### `do-while`

```cpp
do
{
    body;
}
while (condition);
```

Think:

> **Do this once, then keep doing it while the condition is true.**

# 19. Quick Exam/Interview Revision

**What is a loop?**
A loop repeatedly executes a block of code based on a condition.

**When does a `for` loop initialize its variable?**
Once, before the first condition check.

**When is a `for` loop's condition checked?**
Before every iteration.

**When does the update execute?**
After the body and before the next condition check.

**Can all three expressions of a `for` loop be omitted?**
Yes.

```cpp
for (;;)
```

creates an infinite loop.

**Can a `while` loop execute zero times?**
Yes, because its condition is checked before the body.

**Can a `do-while` loop execute zero times?**
No. Its body executes at least once.

**Main distinction between `for` and `while`?**
Usually programmer intent and readability, not fundamental execution capability.

**Typical `for` use:**
Counting/iterating through a sequence.

**Typical `while` use:**
Continuing until some state or condition changes.

**Typical `do-while` use:**
When the body must execute at least once.
